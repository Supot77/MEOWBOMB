# MEOWBOMB

Application source is in [`meowbomb/`](meowbomb/). On Vercel set **Root Directory = meowbomb**, Framework = Next.js and production branch = main.

Follow [Vercel + Neon deployment](meowbomb/DEPLOY-VERCEL.md). The app uses schema `meowbomb` and may share an existing Neon PostgreSQL database with another game. Credentials belong in Vercel environment variables, never in Git.
